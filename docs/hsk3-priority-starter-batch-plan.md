# DuongDuong 学中文 — HSK3 Priority Starter Batch Plan

_Last updated: 2026-05-07_

## 1. Purpose
This file defines the first HSK3 starter batch for DuongDuong 学中文.

The goal is to introduce:
- personal experience
- short storytelling
- reasons and opinions
- broader daily independence vocabulary

---

## 2. Starter batch recommendation
### Recommended size
50 words

### Why 50 first
- enough to test HSK3 identity
- enough to create better lesson contrast from HSK2
- small enough for strong QA

---

## 3. Topic buckets
### Bucket A — Personal Experience
- past events
- life moments
- study / work stories

### Bucket B — Reasons & Opinions
- because / therefore style vocabulary
- opinion language
- reaction language

### Bucket C — Practical Independence
- services
- problem solving
- movement and plans

### Bucket D — Short Reading Support
- context words useful in dialogues and short passages

---

## 4. Selection rule
Choose words that:
- support real expression beyond simple beginner statements
- help the learner explain and compare things
- are common in HSK3-style reading and dialogues

---

## 5. Product note
HSK3 should be the point where the app starts feeling less like a flashcard toy and more like a usable structured learning system.
