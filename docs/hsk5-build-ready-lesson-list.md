# DuongDuong 学中文 — HSK5 Build-Ready Lesson List

_Last updated: 2026-05-07_

## 1. HSK5 goal
HSK5 should help learners:
- read longer and denser texts
- understand abstract and formal vocabulary
- use words with better precision
- improve exam-oriented reading, collocation, and nuance handling

This level should not feel like “harder HSK4 only”. It should feel like:
- broader reading power
- stronger formal expression
- better synonym and collocation control

## 3. Build-ready lesson list
### HSK5-M1-L1
- VI: Xã hội và thay đổi
- ZH: 社会与变化
- Goal: học từ vựng về thay đổi xã hội, xu hướng và hiện tượng chung
- Word target: 35–40
- Quiz focus: meaning, reading context

- VI: Giá trị và trách nhiệm
- ZH: 价值与责任
- Goal: học từ về trách nhiệm, giá trị, lựa chọn, nghĩa vụ

### HSK5-M1-L3

- ZH: 成功与失败
- Goal: học từ về kết quả, cố gắng, áp lực, trưởng thành

## 4. Product note
HSK5 should not be implemented as a single flat vocabulary bank.
It should be split into:
- core review words
- precision words
- reading words
- idiomatic layer

That structure will make HSK5 Focus Mode actually useful.
