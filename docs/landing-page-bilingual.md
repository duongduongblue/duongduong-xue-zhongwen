## 7) FAQ
### Is this app good for beginners?
**EN:** Yes. The current MVP starts with beginner-friendly HSK1 content.  
**中文:** 是的。目前的 MVP 从适合初学者的 HSK1 内容开始。

### Do I need an account?
**EN:** Not for the MVP. Local-first progress is enough to get started.  
**中文:** MVP 阶段暂时不需要账号，本地进度记录就可以开始使用。

### Is this already a full Chinese learning platform?
**EN:** Not yet. It is currently focused on vocabulary, review, quiz flow, and consistency.  
**中文:** 还不是。目前主要专注于词汇、复习、测验流程和学习持续性。
