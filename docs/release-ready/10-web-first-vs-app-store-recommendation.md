# DuongDuong 学中文 — Web First vs App Store Recommendation

## Câu trả lời ngắn
**Có thể lên store, nhưng với 1 người non-tech thì phức tạp hơn web khá nhiều.**

## Vesper chốt đề xuất
### Nên đi theo thứ tự này:
1. **Web public trước**
2. **Beta nhỏ trên web**
3. **Sửa bug + nội dung + flow**
4. **Chỉ lên App Store / Play Store khi đã ổn**

---

## Vì sao web trước hợp lý hơn
### Web có lợi thế
- nhanh public hơn
- không cần chờ review store
- dễ sửa lỗi ngay
- dễ gửi link cho người khác test
- không cần xử lý signing/phát hành mobile ngay
- phù hợp với founder non-tech

### App Store / Play Store khó hơn ở đâu
- cần account nhà phát triển
- cần build app đúng chuẩn mobile
- cần app icon / splash / screenshots / metadata chuẩn
- cần privacy policy / terms / support contact rõ hơn
- cần xử lý lỗi build / signing / package id / bundle id
- có thể bị reject nếu thông tin chưa rõ hoặc app quá sơ sài

---

## Khi nào nên lên store
Chỉ nên làm khi bạn đã có:
- scope ổn định
- lesson flow mượt
- flashcard + quiz không lỗi lớn
- nội dung HSK1 đủ sạch
- landing/demo/feedback đã validate được nhu cầu thật
- ít nhất một vòng beta nhỏ đã xong

---

## Mức độ phức tạp thực tế
### Web public
**Dễ → Vừa**

### Play Store
**Vừa → Khó**

### App Store iOS
**Khó hơn Play Store**

Lý do:
- Apple review thường chặt hơn
- cần thiết bị/test tốt hơn
- nhiều yêu cầu polish hơn

---

## Kịch bản khả thi nhất cho bạn
### Phase 1
- public landing page
- public preview/demo
- public Expo web

### Phase 2
- mời beta users
- thu feedback
- sửa bug + polish

### Phase 3
- lên Play Store trước nếu muốn app store nhanh hơn
- lên iOS sau nếu cần

---

## Kết luận
### Nếu hỏi: “bỏ lên store có phức tạp không?”
**Có, phức tạp hơn web đáng kể.**

### Nếu hỏi: “có làm được không?”
**Có, làm được — nhưng nên sau web-first validation.**

### Khuyến nghị cuối
> **Web first, store later** là con đường khả thi nhất cho DuongDuong 学中文 với một founder non-tech.
