# DuongDuong 学中文 — Web-First Deploy Steps

## Mục tiêu
Ra public bản web trước theo cách dễ nhất.

---

## Cách khả thi nhất
### Option đơn giản
- dùng Expo Web
- deploy static/web qua một nền tảng dễ như Vercel / Netlify / Firebase Hosting

---

## Bước 1
Chạy local:
```bash
cd chinese-learning-app
npm install
npm run web
```

## Bước 2
Kiểm tra:
- Home
- Learn
- Flashcards
- Quiz
- Progress
- landing page HTML

## Bước 3
Chuẩn bị file public:
- landing page
- preview page
- app web
- privacy policy
- terms of use
- feedback form

## Bước 4
Chọn nền tảng deploy dễ
### Vesper khuyên
- Vercel
- Netlify

## Bước 5
Deploy bản web trước
Mục tiêu là có **1 link public** để gửi cho người test.
