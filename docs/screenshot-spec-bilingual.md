# Screenshot Spec — DuongDuong 学中文

## Goal
Create a polished screenshot set for demo, landing page, sharing, and future app presentation.

Languages in this spec:
- English
- 中文

---

## Screenshot set overview
Recommended set: **5 core screens**

1. Home
2. Learn
3. Flashcards
4. Quiz
5. Progress

Optional bonus:
6. Preview concept screen
7. Lesson selection close-up
8. Streak / stats close-up

---

## General visual rules
### English
- Use the warm ivory background consistently
- Keep one focal point per screenshot
- Avoid overcrowded text
- Make Hanzi large and readable
- Show enough UI chrome to feel like a real app
- Keep the bottom navigation visible in at least 3 screenshots

### 中文
- 统一使用温暖的米白色背景
- 每张图只突出一个重点
- 不要放太多文字
- 汉字要大、清楚、容易读
- 保留足够的界面元素，让它看起来像真实 App
- 至少 3 张图保留下方导航栏

## Screen 1 — Home
### Purpose
Introduce the brand and daily learning vibe.

### Must show
- app name: DuongDuong 学中文
- streak
- learned / review / accuracy stats
- a warm hero area

### Suggested headline overlay
**EN:** Learn Chinese in a soft, simple, daily way  
**中文:** 用轻松、温暖、日常的方式学中文

### Framing note
Capture the top area and stats cards clearly.

---

## Screen 2 — Learn
### Purpose
Show structured vocabulary learning.

### Must show
- HSK pills
- progress row
- lesson pills
- one main vocabulary card
- Hanzi + pinyin + meaning + example

### Suggested headline overlay
**EN:** Learn one lesson at a time  
**中文:** 一次学一课，轻松记单词

### Best word card look
Use a visually balanced word with:
- clean Hanzi
- readable pinyin
- short example sentence

---

## Screen 3 — Flashcards
### Purpose
Show the core study habit loop.

### Must show
- flashcard front or back
- know / don't know buttons
- swipe hint

### Suggested headline overlay
**EN:** Flip, review, remember  
**中文:** 翻卡、复习、记住

Use a centered flashcard with large Hanzi.

## Screen 4 — Quiz
### Purpose
Show active recall and lesson-based practice.

### Must show
- question counter

- prompt

### Suggested headline overlay
**EN:** Quick quizzes for daily recall  
**中文:** 用短测验每天巩固记忆

Take one screenshot with untouched options, and one with answer feedback.

## Capture checklist
### Before capture
- choose one clean lesson
- reset to a stable state
- avoid inconsistent progress values
- use readable Hanzi
- keep one visual focus per screenshot

### After capture
- crop consistently
- align spacing if used in a carousel
- keep same color mood across all shots
